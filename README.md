## Neural//Vault — The Synapse Run

A self-contained, browser-playable isometric sci-fi game. Recover all three signal fragments, use pulse to stun nearby sentinels, and reach the extraction gate. You have six hits before the link is severed.

### Play locally

Open `index.html` in a desktop browser, or serve this folder with `python3 -m http.server 3002` and visit `http://localhost:3002`.

### Controls

- **WASD** or **arrow keys** — move
- **Space** — pulse and stun nearby sentinels (recharges automatically)
- **Shift** — quickstep
- **Enter** — start or retry from the end screen
